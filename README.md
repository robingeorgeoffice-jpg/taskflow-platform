# 🚀 TaskFlow

TaskFlow is a modern AI-powered productivity platform designed to help individuals and teams organize work, manage projects, and boost productivity.

Built with a modern frontend stack, TaskFlow focuses on clean UI, responsive design, scalability, and maintainable architecture.

> ⚠️ This project is currently under active development as part of **Project Phoenix**, a long-term journey to build production-grade full-stack applications.

---

## ✨ Features

- 🎨 Modern SaaS Landing Page
- 📱 Fully Responsive Design
- ⚡ Built with React + Vite
- 💙 Tailwind CSS UI
- 🧩 Reusable Component Architecture
- 🔥 TypeScript
- 📌 Active Navigation with Scroll Spy
- 📱 Mobile Navigation Menu
- 🚀 Automatic Deployment with Vercel (Coming Soon)
- 🔐 Authentication with Supabase (Coming Soon)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/<your-username>/taskflow.git
```

### Navigate into the project

```bash
cd taskflow
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open:

```
http://localhost:5173
```
